# Portfolio

Personal site of Mohammud Ibrahim: a pond of ASCII koi, jellyfish and mantas you can feed, plus projects and writing pages.

Plain HTML, CSS and JavaScript with no build step.

- `index.html`: the pond (home page)
- `projects/`: projects
- `writing/`: writing (see the comment in `writing/index.html` to add a post)
- `assets/`: shared styles and theme toggle for the inner pages

Run it locally:

```bash
python3 -m http.server 4173
```

Theme icons are [Phosphor Icons](https://phosphoricons.com) (MIT).
